# 实验室管理系统 PRD 产品需求文档 v0.2 PocketBase 版

## 1. 项目定位

本项目是一个面向约 20 多人实验室使用的轻量级管理系统，用于解决：

1. 物资是否存在、是否可用、放在哪里不清楚；
2. 3D 打印机、服务器使用记录不清楚；
3. 耗材余量低、耗尽、损坏等状态缺少统一上报；
4. 实验室成员缺少统一的登记入口；
5. 管理员缺少低成本的台账维护和备份方式。

本项目不是企业级库存系统，不追求精确库存、复杂审批、复杂权限或外网访问。

系统核心目标：

> 尽可能简单、低维护、局域网可用、毕业后别人仍能接手。

---

## 2. 技术定位

v0.2 采用低维护技术路线：

```text
PocketBase 单文件后端
PocketBase 内置 SQLite
静态 HTML/CSS/JavaScript 普通页面
PocketBase Admin 作为主后台
少量 admin-lite 自定义轻量管理页
少量 pb_hooks / custom route 实现关键业务逻辑
systemd 开机自启
本机自动备份 + 手动网盘备份
```

明确不使用：

```text
Vue
React
FastAPI
Django
Node 后端
PostgreSQL
Docker
Nginx
云服务器
微信小程序
普通用户账号系统
```

## 3. 用户角色

### 3.1 普通成员

普通成员不登录。

普通成员可以：

1. 查看物资列表；
2. 查看设备状态；
3. 登记设备使用；
4. 上报已有物资状态；
5. 上报新物资；
6. 通过二维码进入系统。

普通成员不能：

1. 直接修改正式物资台账；
2. 直接修改设备基础信息；
3. 删除数据；
4. 审核上报；
5. 进入 PocketBase 管理后台。

### 3.2 管理员

管理员使用 PocketBase Admin 账号。

管理员可以：

1. 使用 PocketBase Admin 查看和修正所有数据；
2. 使用 admin-lite 审核物资状态上报；
3. 使用 admin-lite 审核新物资上报；
4. 查看当前 active 设备使用记录；
5. 手动关闭设备使用记录；
6. 导出 CSV；
7. 管理基础数据；
8. 维护备份和部署。

## 5. 普通用户端页面

### 5.1 首页 `index.html`

首页内容：

1. 系统标题；
2. 当前设备状态摘要；
3. 常用操作大按钮；
4. 物资提醒摘要；
5. 管理员入口链接。

首页按钮：

```text
设备使用登记
查看设备状态
查看物资列表
物资状态上报
新物资上报
```

设计要求：

1. 手机优先；
2. 大按钮；
3. 不要求登录；
4. 每个入口清晰；
5. 页面加载失败时显示错误提示。

---

### 5.2 设备状态看板 `equipment.html`

展示所有启用设备。

每台设备显示：

1. 设备名称；
2. 设备类型；
3. 位置；
4. 当前派生状态；
5. 当前登记人；
6. 开始时间；
7. 预计结束时间；
8. 开始新登记按钮。

设备派生状态：

```text
空闲
使用中
预计已完成，待确认
维护中
停用
```

派生规则：

1. 设备停用则不显示或显示停用；
2. 设备维护中则显示维护中；
3. 没有 active 使用记录则空闲；
4. 有 active 记录且未超过预计时间则使用中；
5. 有 active 记录且超过预计时间则预计已完成，待确认；
6. 预计时间为空则显示使用中。

---

### 5.3 设备使用登记 `equipment-use.html`

字段：

1. 使用人；
2. 使用设备；
3. 预计使用时间；
4. 使用材料；
5. 备注。

使用人规则：

1. 优先从 `lab_members` 选择；
2. 允许临时手填；
3. 临时手填不自动加入成员名单。

设备规则：

1. 只显示启用且可用的设备；
2. 支持 URL 参数自动预选设备：

```text
/equipment-use.html?equipment_id=设备ID
```

预计时间固定选项：

```text
1小时内 = 60
2小时 = 120
4小时 = 240
8小时 = 480
12小时 = 720
24小时 = 1440
不确定 = 空
```

使用材料规则：

1. 可选；
2. 支持多选；
3. 只能选择已有启用物资；
4. 不记录消耗数量。

提交规则：

1. 调用 custom route，不直接写 `equipment_usage`；
2. 如果同一设备存在 active 记录，则自动关闭旧记录；
3. 创建新 active 记录；
4. 返回首页或继续登记。

---

### 5.4 物资列表 `items.html`

展示所有启用物资。

支持：

1. 搜索；
2. 按类型筛选；
3. 按状态筛选；
4. 按位置筛选；
5. 点击进入状态上报。

物资卡片字段：

1. 名称；
2. 类型；
3. 规格；
4. 状态；
5. 位置；
6. 备注；
7. 是否存在待审核上报；
8. 上报状态按钮。

---

### 5.5 物资状态上报 `item-report.html`

字段：

1. 上报人；
2. 选择物资；
3. 上报状态；
4. 备注。

规则：

1. 上报后进入 `item_reports`；
2. `review_status` 默认为 `待审核`；
3. 不直接修改 `items.status`；
4. 支持 URL 参数自动预选物资：

```text
/item-report.html?item_id=物资ID
```

---

### 5.6 新物资上报 `new-item-report.html`

字段：

1. 上报人；
2. 物资名称；
3. 物资类型；
4. 规格；
5. 初始状态；
6. 位置；
7. 位置补充；
8. 备注。

规则：

1. 上报后进入 `new_item_reports`；
2. `review_status` 默认为 `待审核`；
3. 不直接创建正式物资；
4. 管理员审核通过后才创建 `items` 记录。

## 6. 管理员端设计

### 6.1 PocketBase Admin

访问：

```text
http://服务器IP:8090/_/
```

用途：

1. 查看原始数据；
2. 手动修改数据；
3. 管理 Collections；
4. 管理管理员账号；
5. 紧急修正错误数据。

定位：

> 电脑端维护工具，不要求手机适配。

### 6.2 admin-lite

访问：

```text
/admin-lite.html
```

用途：

1. 待审核物资状态上报；
2. 待审核新物资；
3. 当前 active 设备记录；
4. 手动关闭设备记录；
5. CSV 导出；
6. 跳转 PocketBase Admin。

定位：

> 日常轻量管理页，需要手机和电脑双端适配。

适配方式：

1. 手机端使用卡片布局；
2. 电脑端使用表格或宽卡片布局；
3. 不开发两套页面；
4. 用响应式 CSS 实现。

## 7. 初始化数据

### 7.1 初始成员

只录入研究生成员。

不录入：

```text
本科生
临时访客
已毕业成员
外来人员
```

临时人员通过普通页面手填姓名登记。

### 7.2 初始设备

首批只录入：

```text
服务器 A
服务器 B
3D 打印机
```

其他设备等盘库时再看。

### 7.3 初始物资

按物资类型盘库并手动网页录入。

盘库类型顺序：

```text
3D打印材料
机械耗材
电子元件
化学材料
工具
其他
```

不做 Excel 导入。

## 8. 位置编号

位置编号：

```text
A区
B区
C区
D区
E区
F区
未分类
其他
```

管理员可维护每个位置说明。

首次盘库时可以暂定：

```text
A区：3D打印材料
B区：服务器/设备区
C区：机械耗材
D区：电子元件
E区：化学材料
F区：工具/其他
```

实际说明以后可在后台改。

## 9. 二维码入口

需要生成：

1. 总入口二维码：

```text
http://服务器IP:8090/
```

2. 设备登记二维码：

```text
http://服务器IP:8090/equipment-use.html
```

3. 单设备预选二维码：

```text
http://服务器IP:8090/equipment-use.html?equipment_id=设备ID
```

二维码只作为网页入口，不做物资二维码管理。

## 10. 数据导出

v0.2 默认使用 CSV 导出，原因是：

1. 实现简单；
2. 无额外后端依赖；
3. Excel 可直接打开；
4. 后期维护更容易。

导出类型：

1. 物资台账 CSV；
2. 物资状态上报 CSV；
3. 新物资上报 CSV；
4. 设备使用记录 CSV。

如后续必须使用 `.xlsx`，可另做脚本，不纳入 v0.2 必做功能。

## 11. 验收标准

### 普通端

1. 手机可打开首页；
2. 可查看设备状态；
3. 可扫码进入设备登记；
4. 单设备二维码可自动预选设备；
5. 可登记设备使用；
6. 新登记可自动关闭旧 active 记录；
7. 可查看物资列表；
8. 可上报物资状态；
9. 可上报新物资；
10. 所有表单提交后有成功或失败提示。

### 管理端

1. PocketBase Admin 可登录；
2. admin-lite 可打开；
3. admin-lite 手机和电脑均可使用；
4. 可审核物资状态上报；
5. 可审核新物资；
6. 可查看 active 设备记录；
7. 可手动关闭 active 设备记录；
8. 可导出 CSV。

### 部署维护

1. systemd 可开机自启；
2. 可用命令查看状态和重启；
3. 每日本机备份可生成；
4. 可手动上传网盘；
5. 文档说明 pb_data 不能删除；
6. 有恢复流程说明。
